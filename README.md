# Python Fundamentals Project

## Overview
This project was completed as part of a **Data Technician Bootcamp** and demonstrates key Python programming concepts used to create interactive programs, perform calculations, and implement logical decision-making. The project focused on building a strong foundation in programming by applying core Python features to real-world scenarios and problem-solving exercises. 【1-3d8a0e】

## Skills Demonstrated

### Variables and Data Types
- Created and managed variables to store user input and calculated values.
- Worked with different data types including strings, integers, and floating-point numbers.
- Applied type casting to convert data between formats for processing and calculations.

### User Interaction
- Used `input()` to collect information from users.
- Used `print()` to display results, instructions, and feedback.
- Built user-friendly programs that responded dynamically to user input.

### Decision Making
- Implemented `if`, `elif`, and `else` statements to control program flow.
- Created logic to validate inputs and handle different scenarios.
- Applied conditional statements to solve tasks such as determining even/odd numbers, checking leap years, and validating ATM transactions. 【1-3d8a0e】

### Loops and Iteration
- Used `for` loops to process ranges of values and automate repetitive tasks.
- Used `while` loops to create menu-driven applications and repeated user interactions.
- Applied iteration to exercises such as generating number sequences, checking prime numbers, and implementing the FizzBuzz challenge. 【1-3d8a0e】

### Calculations and Problem Solving
- Developed programs to calculate:
  - Sums and averages
  - Temperature conversions
  - Rectangle areas
  - Compound interest
  - Date and time-related calculations
- Applied arithmetic operators and logical reasoning to produce accurate results. 【1-3d8a0e】

### Practical Programming Projects
- Built interactive console applications.
- Developed an ATM simulation using functions, loops, conditional statements, and user input.
- Created solutions for common programming challenges focused on logic and algorithm development. 【1-3d8a0e】

## Key Learning Outcomes
Through this project, I gained hands-on experience in:
- Writing structured and readable Python code.
- Developing logical problem-solving skills.
- Creating interactive programs that respond to user input.
- Using programming constructs to automate tasks and perform calculations.
- Building a solid foundation for data analysis and more advanced Python programming.

## Technologies Used
- Python
- Google Colab
- Jupyter Notebooks
